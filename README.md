# 我的世界猜谜

Koishi 猜谜插件，题库包含《我的世界》的生物、物品和方块。

## 安装

```sh
yarn add koishi-plugin-mcdle
```

在 Koishi 中启用，并安装 `database` 服务。图片输出可选，需要 `puppeteer` 服务。

## 指令

| 指令 | 说明 |
| --- | --- |
| `mcdle` | 查看玩法与指令 |
| `mcdle.猜 [名称]` | 开局或提交猜测 |
| `mcdle.裸猜 [开/关]` | 切换本频道无前缀续猜 |
| `mcdle.排行榜` | 查看本群战绩 |
| `mcdle.词库` | 查看全部词条 |

首次猜测的词条决定题目类型。提示中，🟩 表示完全匹配，🟨 表示部分匹配，🟥 表示不匹配；🟥⬆️ 和 🟥⬇️ 表示答案更大或更小。裸猜设置仅对当前群有效，插件重载后恢复默认。

## 显示与交互

发送 `mcdle.显示 文字` 或 `mcdle.显示 图文` 切换个人显示偏好。同一机器人中的配套插件共享选择，重启后恢复图文。图文模式中的信息图片附带文字说明；作品素材与感官测试的适用边界见 [设计系统](./DESIGN_SYSTEM.md)。

本次更新：猜测历史保留完整属性文字，棋盘改为两列属性卡；个人文字模式和裸猜冲突保护。
